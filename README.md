# WLED-Project


This is the project where i am making a custom housing for my ESP32 running WLED. The ESP32 runs WLED then a DC power outlet is going to provide 12 volts to the LED strips as well, 5 volts to the esp32 for it to turn on. For that I need a convertor and all of that is going to be stored on the bottom. The LED strip is going to get power with the barrel jack giving 12 volts to the convertor then convert it to 5 and then going to give a pig tail led connector. The esp32 communication io pin is also going to be connected to the pig tail connector. For more info visit the google drawing for a simpler understanding.
